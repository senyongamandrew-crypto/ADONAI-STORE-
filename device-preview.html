Sign in once first. The register and the dashboards open the login gate in a fresh browser profile — unlock the POS (or the Admin Suite passkey) in a normal tab of this same address, then return here and the frames render the real screens. Changing Display size here uses the exact same saved setting as Menu → Display size inside the app (adonai.ui.display-size), so what you tune here is what the phone keeps.

Frames are true CSS-pixel viewports (a 780 × 360 frame is a phone held in landscape), so each frame triggers exactly the media queries that device would. Phone frames are expected to use the compact, phone-sized type scale; the laptop frame keeps the full-size scale. Wide frames scroll horizontally.
