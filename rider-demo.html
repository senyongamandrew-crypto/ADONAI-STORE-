🧪 Browser demo — how the rider app operates

This page runs the real rider interface and the real dispatch API, with the Android native layer (pairing storage + GPS foreground service) simulated in the browser. On a phone, this same screen lives inside the installed Adonai POS APK under Menu → Rider delivery app.

  1. Pair the phone — the form below is pre-filled with the demo pairing code DEMORIDERS. Tap Pair this phone. (In real life the dispatcher issues a single-use 10-minute code.)
  2. Start sharing — approve the simulated Android consent dialog. Simulated GPS fixes around Kampala are sent every 5 seconds (flagged mock:true, so the dispatch console honestly labels them “simulated”).
  3. Work the delivery — the assigned paid order appears under Active deliveries. Walk it through: Accept → Collected → Arrived → Delivered (the last step requires a recipient name). Add a second job from the dispatch console.
  4. See dispatch’s side — open Delivery Partners & Dispatch ↗ and unlock it with the orders password adonai-demo-1: watch the GPS marker, the rider’s job progress and the notification bell.

Only the latest GPS fix is stored — never a route trail. Background tracking with the screen locked needs the real installed APK; force-stop, battery savers and lost network can interrupt updates even there.

📲 Install the real Adonai Delivery app on this phone
⬇ Download Adonai Delivery APK (GitHub) ⬇ Download Adonai Delivery APK (this server)
Both buttons deliver the same signed rider build: adonai-delivery.apk. It installs as Adonai Delivery (com.adonaithrift.delivery; branch preview builds read Adonai Delivery Preview) with the lime boda icon, and opens straight into rider sign-in — it contains no cashier register. If a download is named adonai-pos-v2.apk or opens the shop register, that is the separate Adonai POS cashier app, not this one. Android will warn that APKs “may be harmful” outside the Play Store — that is normal; choose Download anyway. Then allow “Install unknown apps” for your browser/Files, open the downloaded file and tap Install. Sign in with your rider account, check in for the day, then enter the App code from dispatch. Screen-locked background GPS pairing (this demo's native path) lives in the POS APK under Menu → Rider delivery appadonai-pos-v2.apk. SHA-256 checksums ship with every build in GitHub Releases (SHA256SUMS.txt). Minimum Android 5.1.
